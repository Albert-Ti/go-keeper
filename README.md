# GoKeeper

## Auth

1. При регистрации пользователь обязан будет подтвердить почту, тут есть 2 способа: если подключен SMTP server, то код придет на почту, если нет, то придет на клиент(вообще этого в проде не должно быть, но это сделано для упрощения ревью)
2. Если пользователь не подтвердил почту, то при попытке залогироватся его перенесет на
   страницу подтверждения где ему предоставится возможность подтвердить (произойдет обновление кода в базе и отправка нового кода)
